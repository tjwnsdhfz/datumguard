# 건축 작업 파일과 검증 흐름

## 대상과 가치 가설
반복해서 치수를 수정하는 건축 학습자·소규모 설계 작업자가 편집 입력과 검증 근거를 함께 남기는 흐름이다. 일반 뷰어와 달리 요구 치수와 생성 파일의 재측정 결과를 연결한다. 이 차이에 대한 지불 의향은 아직 검증되지 않았다. 구조·인허가·법규 인증을 제공하지 않는다.

## 사용
1. 기본 예제를 편집하거나 직접 저장한 DatumGuard JSON을 선택한다.
2. 파일 검사와 요약을 확인하고 `이 작업 열기`를 선택한다. 기존 작업은 실행 취소로 돌아간다.
3. 객체 선택과 수치 입력으로 수정한다. 작업 파일 저장은 편집 입력의 백업이며 검증 증명서가 아니다.
4. 검증을 실행한다. 입력을 변경하면 기존 결과는 무효가 되며 늦게 도착한 응답도 적용하지 않는다.
5. 통과한 결과만 DXF·PDF·JSON 묶음으로 다운로드한다. 실패 항목을 고친 뒤 다시 검증한다.

형식은 datumguard-architecture/version 1, 최대 1MB, 객체 종류별 200개다. 필드·좌표·중복 ID·벽 참조를 검사한다. 임시 저장은 30일 TTL이므로 파일 백업을 권장한다. 파일 선택은 로컬 처리이며 검증 실행 때 현재 입력이 API로 전송된다.

## 디자인
밝은 작업 화면, 짧은 3단계 안내, 프로젝트 이름·저장·열기를 한 영역에 모았다. 44px 조작 영역, 키보드 포커스, 오류와 가져오기 요약, 모바일 세로 배치를 제공한다. 기존 전문 작업 공간은 유지했다.

## 검증과 운영
단위 테스트는 malformed/oversize/중복 ID/잘못된 참조를 검사한다. 브라우저 회귀는 저장→파일 확인→열기→실행 취소, 잘못된 파일 보존, 늦은 검증 응답 무효화와 기존 CAD 편집·검증을 검사한다. CI의 기존 CAD·보안·컨테이너 검사를 유지한다.

최종 웹 이미지에서는 node로 직접 서버를 실행하며 불필요한 npm/yarn을 제외했다. CVE-2026-59873이 포함된 빌드 도구를 실행 이미지에 남기지 않기 위한 조치다.

신규 AI 호출·유료 서비스·DB 변경 없음. 추가 사용료 0원은 현재 프로토타입의 기존 호스팅 조건에서의 가정이며 전체 계정 청구액 보장은 아니다. Vercel Hobby는 비상업적 사용 제한이 있으므로 유료 운영 전 현재 요금제와 상업 이용 가능한 호스팅을 확정해야 한다. Render Free는 cold start와 자원 제한이 있어 유료 SLA를 제공할 수 없다.

복구는 이 변경 커밋을 revert 후 CI와 배포 smoke를 재실행한다. 사용자 파일과 IndexedDB 스키마는 변경하지 않았다. 실제 고객 파일·장시간 사용·지불 의향은 별도로 검증해야 한다.
